# PiDevSymfony - FinTrack Web Platform

A modern Symfony-based FinTech web application designed to centralize and simplify personal financial management through a secure and intelligent platform.

---

## 🚀 Project Overview

PiDevSymfony is the web version of the FinTrack ecosystem developed using Symfony framework.

The application provides users with advanced financial management tools including:

- Account management
- Portfolio management
- Budget tracking
- Products & services management
- Financial document management

The platform aims to improve financial visibility, simplify daily financial tasks, and provide a modern user-friendly experience.

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/younsiahmed9/Pidevsymfony.git
```

Move to the project directory:

```bash
cd Pidevsymfony
```

Install dependencies:

```bash
composer install
```

Configure the `.env` file with your database credentials.

Run database migrations:

```bash
php bin/console doctrine:migrations:migrate
```

Start Symfony server:

```bash
symfony server:start
```

---

## 🗄️ Database Configuration

Update your `.env` file:

```env
DATABASE_URL="mysql://username:password@127.0.0.1:3306/fintrack"
```
